# Vocabulary profile for WORK calls - Power BI reporting, Azure DevOps,
# Kusto/IcM and scrum ceremonies. Use it instead of domain_vocab.txt when the
# recording is a scrum call, a KT session or a client sync:
#
#   python transcribe.py "call.mkv" --vocab vocab_work.txt --language en
#
# A sibling vocab_work.local.txt (git-ignored) is loaded FIRST if it exists.
# That is where person names and internal project names belong, so they never
# get committed to a shared repository.
#
# Only the terms that fit Whisper's hotword prompt are used, in file order, so
# keep the most important ones at the TOP. The script prints how many fit.
#
# One term per line. Blank lines and lines starting with # are ignored.
